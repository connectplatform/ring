# Ring Platform

Welcome to the community documentation for **Ring Platform** — the open-source collaboration stack (Next.js, Auth.js, PostgreSQL).

Self-host with [`install.sh`](/docs/getting-started) once guides are published for your clone, or browse the [GitHub repository](https://github.com/connectplatform/ring).

Empire / Ringdom hosted docs and settler playbooks ship via the `ring-platform-org` overlay — not this community tree.
