# Інтеграції

**Підключіть клон Ring до сервісів, якими вже користується ваша спільнота** — платіжні рейки, EVM-гаманці, OAuth, Firebase push, бізнес-пошта та автоматизація — через конфігуровані адаптери, описані в цій секції.

<Callout type="success" title="Коротко">
Ring не прив’язує вас до одного вендора. Оператори вмикають інтеграції через **`ring-config.json`**, **`.env.local`** і задокументовані модулі: **PaymentConductor**, **Wagmi v3**, **Auth.js v5**, **FCM**, **Email AI-CRM** та **REST / Tunnel / MCP**. Почніть з [Конфігурації середовища](/docs/deployment/environment).
</Callout>
