# Наступні кроки

Bootstrap завершено — дослідіть можливості Ring, потім створіть першу організацію та можливість.

<RingWelcomeFeatureExplorer locale="uk" />

## Негайні дії

1. Відкрийте панель адміністратора за адресою `/admin`.
2. Створіть першу сутність за адресою `/entities/add`.
3. Опублікуйте можливість за адресою `/opportunities/add`.
4. Перевірте обмін повідомленнями та сповіщення в живому UI.
5. Налаштуйте брендинг у [Кастомізації](/docs/customization).

Готові до продакшену? Продовжіть з посібниками [Розгортання](/docs/deployment).
</Callout>
