# 📘 Для засновників

Цей індекс — куратований docTree для **засновників, операторів та осіб, що приймають рішення**, які керують платформою на базі Ring. Кожна секція посилається на сторінку-індекс секції та містить лише статті, що пояснюють бізнес-цінність, модель доходу або операційний процес.

<Callout type="info">
  Використовуйте перемикач **Founder** / **Developer** у бічній панелі документів, щоб перемикатися між цим поданням та [Для розробників](/uk/docs/for-developers). Статті з контентом для обох аудиторій (як SubscriptionConductor) з'являються в обох індексах.
</Callout>

## 💡 Функції (бізнес-цінність)

[**Функції** →](/uk/docs/features) — Кожна функція Ring з коротким описом бізнес-цінності.

### Дохід та комерція
- [SubscriptionConductor](/uk/docs/features/subscriptions) — Регулярний дохід через мульти-провайдерні членські підписки (Stripe, WayForPay, RING-кредит, ончейн-токен, NFT-гейт).
- [PaymentConductor](/uk/docs/features/payment-conductor) — Єдина оркестрація платежів для магазину, членства та промоції новин.
- [Мультивендорний магазин](/uk/docs/features/store) — Комісії маркетплейсу та прямі продажі.
- [Партнерські програми](/uk/docs/features/affiliate-enablement) — Партнерські посилання та частка доходу.
- [Refcodes](/uk/docs/features/refcodes) — Прив'язані до гаманця URL-адреси та ончейн-винагороди.
- [Гаманець](/uk/docs/features/wallet) — Екосистема RING, DAAR, DAARION.
- [NFT ринок](/uk/docs/features/nft-market) — White-label NFT-торгівля.
- [Стейкінг](/uk/docs/features/staking) — Мульти-пул пасивного доходу.

### Аудиторія та спільнота
- [Суб'єкти](/uk/docs/features/entities) — Верифіковані професійні мережі та B2B-каталоги.
- [Можливості](/uk/docs/features/opportunities) — Двоприродний ринок (пропозиції + запити).
- [Повідомлення](/uk/docs/features/messaging) — Спілкування в реальному часі.
- [Блог учасників](/uk/docs/features/member-blog) — Довгий контент від ваших учасників.
- [Публічний профіль](/uk/docs/features/public-profile) — SEO-дружні публічні сторінки.
- [Резервація імен](/uk/docs/features/username-reservation) — Маркетплейс брендованих хендлів.
- [Науковий редактор](/uk/docs/features/scientific-editor) — Спільне редагування з AI-агентом.
- [Новини](/uk/docs/features/news) — Новинна студія з AI-допомогою у написанні.

### Охоплення та залученість
- [Сповіщення](/uk/docs/features/notifications) — Система сповіщень у застосунку.
- [Push-сповіщення (FCM)](/uk/docs/features/push-notifications-fcm) — Мобільний push-канал.
- [Email AI-CRM](/uk/docs/features/email-ai-crm) — AI-асистент для поштових скриньок `info@`.
- [Tunnel Protocol](/uk/docs/features/tunnel-protocol) — Реалтайм без перезавантажень.
- [VideoConductor](/uk/docs/features/video-conductor) — Скриптована AI-відеопродукція.

### Довіра та локалізація
- [Автентифікація](/uk/docs/features/authentication) — Auth.js v5 з кількома провайдерами.
- [Безпека](/uk/docs/features/security) — Постура безпеки та комплаєнсу.
- [Система локалей](/uk/docs/features/locale-system) — Мульти-локальна архітектура (EN/UK/RU тощо).
- [Мобільний досвід](/uk/docs/features/mobile-experience) — PWA та мобільний веб.
- [Продуктивність](/uk/docs/features/performance) — Web vitals та runtime-витрати.
