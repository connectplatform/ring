## AI-orchestrated opportunity matching

Traditional platforms are passive databases. Ring **actively hunts** for matches and pushes DMs when confidence exceeds your threshold.

### How the matcher pipeline works

<Steps>

<Step>

### AI analyzes the profile (8 factors)

Ring's **[8-factor AI matching engine](/docs/features/opportunities)** scores skills, interests, availability, location, experience, growth vector, culture fit, and success patterns.

<Code language="typescript" title="Profile analysis (server-side matcher)">
{`const profileAnalysis = await aiMatcher.analyzeProfile({
  user: currentUser,
  depth: 'comprehensive',
  factors: 8,
})

// { skillScore, interestAlignment, availabilityMatch, overallMatch, confidence }`}
</Code>

</Step>

<Step>

### Matcher scans 24/7

New opportunities are compared against profiles in real time — serendipitous connections without manual search.

</Step>

<Step>

### DM notification payload

When match confidence is high, inbox + tunnel deliver a structured notification:

<Code language="typescript" title="Example DM notification payload">
{`{
  title: "Perfect Match: Senior React Developer",
  explanation: "React 19 + Next.js + remote preference = ideal fit (95% match)",
  confidence: 0.95,
  factors: { skills: 0.98, interests: 0.94, availability: 0.92 },
  action: "View Opportunity",
}`}
</Code>

</Step>

<Step>

### Collective intelligence loop

Every accept/decline/success teaches the matcher — accuracy improves as the community uses Ring.

<Mermaid title="Network effect">
{`graph LR
    U1[Users] --> AI[AI Engine]
    AI --> Learn[Learning Loop]
    Learn --> Better[Better Matches]
    Better --> U1`}
</Mermaid>

</Step>

</Steps>

</Audience>
