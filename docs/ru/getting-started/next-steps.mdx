# Следующие шаги

Bootstrap завершён — изучите возможности Ring, затем создайте первую организацию и возможность.

<RingWelcomeFeatureExplorer locale="ru" />

## Немедленные действия

1. Откройте панель администратора по адресу `/admin`.
2. Создайте первую сущность по адресу `/entities/add`.
3. Опубликуйте возможность по адресу `/opportunities/add`.
4. Проверьте обмен сообщениями и уведомления в живом UI.
5. Настройте брендинг в [Кастомизации](/docs/customization).
