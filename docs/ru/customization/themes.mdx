# Темы (Tailwind CSS v4)

- Обновляйте дизайн-токены с помощью CSS-переменных
- Предпочитайте утилитарные классы и `tailwind-merge`
- Используйте Radix UI для доступных примитивов
- Тестируйте тёмные, светлые и системные темы
- Избегайте глобальных переопределений; применяйте стили в рамках компонентов
