# Интеграции

**Подключите клон Ring к сервисам, которыми уже пользуется ваше сообщество** — платёжные рельсы, EVM-кошельки, OAuth, Firebase push, бизнес-почта и автоматизация — через конфигурируемые адаптеры в этой секции.

<Callout type="success" title="Кратко">
Ring не привязывает вас к одному вендору. Операторы включают интеграции через **`ring-config.json`**, **`.env.local`** и задокументированные модули: **PaymentConductor**, **Wagmi v3**, **Auth.js v5**, **FCM**, **Email AI-CRM** и **REST / Tunnel / MCP**. Начните с [Конфигурации окружения](/docs/deployment/environment).
</Callout>
